# Daily Mission and Capability Check Pilot

Date: 2026-09-25. Status: implemented and verified for the three pilot days.

This iteration adds a lightweight, evidence-based check to selected Mastery steps. It does not replace the broader listening and speaking pilot in `docs/iterations/listening-speaking-pilot/`, and it does not claim automatic pronunciation or grammar assessment.

## Documents

1. [Requirements](./requirements.md)
2. [Content samples](./content-samples.md)
3. [Technical design](./technical-design.md)
4. [Acceptance](./acceptance.md)

## Delivered Scope

- A concise daily mission in the Today header.
- A Listen -> Respond -> Check flow under Mastery on Days 1, 24, and 26.
- Results of Independent, With help, or Practice again.
- Review scheduling after 7, 3, or 1 day respectively.
- Due capability checks in Review.
- Only Independent results in Me > Scenes I Can Describe.
- IndexedDB migration to version 9 with no destructive data conversion.

Non-pilot days keep the existing course flow.
