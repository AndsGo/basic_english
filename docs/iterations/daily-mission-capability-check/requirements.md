# Requirements

## Product Goal

The learner should finish selected lessons by using Basic English to understand a short message and express a complete everyday meaning, not only by recognizing words and patterns.

## Functional Requirements

- **R01 Daily mission:** Today shows one concrete outcome for the current pilot day.
- **R02 Mastery placement:** The capability check appears once under Mastery. It is not repeated in Words, Patterns, or Output.
- **R03 Listening evidence:** The learner plays the prompt, or reads the fallback when speech is unavailable, and chooses the correct meaning.
- **R04 Output evidence:** The learner writes at least three short sentences covering the stated ideas.
- **R05 Layered support:** Keywords, sentence starters, and a reference answer are optional. Opening support is recorded for the attempt.
- **R06 Honest result:** Clear and complete output without opened support is Independent. Clear and complete output with support is With help. Other saved output is Practice again.
- **R07 Progression:** A pilot day's Mastery Continue button remains disabled until the check is saved. Existing mastery review requirements still apply.
- **R08 Review:** Results return after 7 days for Independent, 3 days for With help, and 1 day for Practice again. Only the latest result for each capability is due.
- **R09 Outcome view:** Me lists only latest Independent results under Scenes I Can Describe, while showing all latest result states separately.
- **R10 Compatibility:** Non-pilot days and repositories without capability-check methods keep the existing behavior. The legacy scene map remains a repository compatibility fallback.

## Product Language

The product reports learner evidence and self-assessment. It must not claim that the writing is grammatically correct, that pronunciation was assessed, or that the capability is permanently mastered.
