## 真机矩阵

- Windows Chrome、Edge：录制/回放/重启页面、权限拒绝、连续切换。
- macOS Safari：同上，验证实际 MIME 与保存后回放。
- iOS Safari、Android Chrome：用户手势播放、授权、后台中断、旋转与小屏。
- 版本号在执行时登记；不支持的环境必须进入可跳过降级路径。没有设备就记为未验证，不能填通过。
- Playwright 注入录音数据验证功能流；真实麦克风与浏览器 TTS 单独人工验证。自动化假音频不构成声音质量验收。
