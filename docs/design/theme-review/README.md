# 主题色彩与按钮调整

日期：2026-10-28。规范版本：1.1。范围：应用基础样式与独立设计预览的主题颜色、原生控件、按钮状态及语义记录表面。

## 调整内容

设置页的单选与复选原先使用浏览器默认蓝色；部分教学记录使用固定浅色值。现在通过 color-scheme 与 accent-color 让原生控件跟随主题，固定蓝灰说明底改为暖灰，语义记录改用主题变量。

| 组件角色 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 主按钮 | 深绿 #265C46，白字 | 鼠尾草绿 #9DB9A6，深色字 #17251C |
| 主按钮悬停 | 绿底加深至 #1F4D3B | 绿底柔和提亮至 #B0C9B8 |
| 主按钮按下 | #173E2C | #8BAA97 |
| 导航与模式选中 | 浅绿底、深绿字 | 低亮度绿底、绿灰字 |
| 当前播放与答案选中 | 主题高亮底与明确边界 | 主题高亮底与明确边界，区别于主按钮 |
| 禁用 | 暖灰实体底与可读文字 | 深灰绿实体底与可读文字 |
| 原生选项与焦点 | 绿色强调 | 低饱和绿色强调 |

选中按钮的悬停曾被普通按钮底色覆盖，可能遗留白色前景。现在同时定义选中、悬停和焦点的前景背景，避免浅底白字。禁用按钮使用专门的文字和背景，不把整体透明度降低成难以辨认的色块。

深色主按钮的文字对比度为默认 7.53:1、悬停 9.02:1、按下 6.29:1；深色选中态为 6.66:1。正常、悬停和键盘焦点下的应用按钮均经过浏览器检查。平台管理的原生弹出面板仍可能保留系统自己的样式。
