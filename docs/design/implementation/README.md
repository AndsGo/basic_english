# 页面规范应用记录

日期：2026-10-29。依据：[DESIGN.md](../../../DESIGN.md) 1.1。这里展示实际 React 应用，独立设计预览仍保留为参考。

已接入的页面与行为：

- 全局：暖白与森林绿语义色、深色鼠尾草绿操作、阅读式页面标题、统一表单与焦点。桌面导航位于顶部，手机保留五项底部导航，页眉显示真实的 52 周课程。
- Today：当前目标与练习优先；用 Review、Learn、Practice、Use it 表示阶段，完整细步骤可展开查看。原有完成条件、能力练习与课程推进继续使用原逻辑。
- Course：52 周纵向目录，默认展开当前周；各周可独立打开，日次、锁定条件、完成和待复习状态来自现有进度。
- Review：统一任务标题、说明、卡片和操作层级；到期计算、掌握复习及能力复习保留原实现。
- Words：保留 List、Flashcards、850 Library、Stories 四个入口。书架从正式故事数据读取 53 篇绘本，使用第一页完整插画作为封面，支持书名或目标词搜索、已读筛选、课程阶段筛选及清空筛选。目录显示建议阅读周次，不额外锁定故事。
- 阅读：封面进入读前介绍，再进入专注阅读；隐藏全局导航，保留返回书架和换书入口。正文自然排版，长内容在正文区滚动，控制栏位置稳定。翻页自动朗读、禁用语音、中文帮助及语义记录保持有效。返回书架恢复当前筛选、滚动和封面焦点。
- 记录：可选的 pageIndex、lastOpenedAt 字段兼容旧记录；有效位置恢复到原页，越界或非法位置回到第一页。读完、答题、保存表达、加入复习与已认识状态仍独立。Me 展示实际保存的绘本句子，并统一设置行。

应用直接使用课程、绘本、存储和语音服务；未接入设计预览中的示例进度。没有新增教学图片，也没有改变 850 词内容或复习规则。
